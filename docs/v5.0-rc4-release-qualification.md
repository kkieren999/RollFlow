- RC3 run 45986977569: PostgreSQL job failed with DeadlockDetected in the competing school closure/attendance test, while attendance tried to lock the imported timetable row. Added deterministic PostgreSQL regression for foreign-key insert while an account writer holds its lock; competing account mutation must still fail nowait. Retained competing closure/attendance test and added revision/notice assertions. No retries, swallowed deadlocks or relaxed security assertions.
