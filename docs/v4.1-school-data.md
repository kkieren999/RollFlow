# V4.1 School data and OneSchool integration — staging

Uses existing dated timetable CSV, SM110 student Excel, ExportStudentClass CSV, line alignment and staff PDF import workflows. Adds one admin-only source and publication centre: source freshness, candidate changes, duplicate/overlap and empty-roster diagnostics, private import history, publication history. New dated publications carry validation version; if the latest applied student or membership source changes or is purged, attendance blocks until reviewed republish. Older legacy snapshots without provenance still require migration/review before production. No automated student withdrawal or inference from absence in a report.

Exact duplicate publication is a no-op to preserve rolls. Replacement with recorded rolls requires explicit acknowledgement. Safe restoration is deliberately limited to a historically stored dated snapshot that rebuilds byte-equivalently from current reviewed sources and identities, with no rolls in affected dates; creates a new publication, never rewrites historical rows or activates old class grants. Full import rollback (restoring directory fields, historical enrolment intervals and old sources) is not implemented; use reviewed backup/restore under approved procedures, never silently reactivate a stale snapshot.

Migration 0018 adds AttendanceTransferReview. Full system administrators can review and export an individual submitted revision as a private LOCAL REVIEW CSV, validated against frozen roster, original publication identities and submission history. No names, passwords or student details in audit payload. Spreadsheet formula/control values blocked. Manual attestation requires exact exported digest; recorded once, not external confirmation. Format is not an approved OneSchool interchange format. No automated API, upload, credentials, code mapping or actual official attendance updates; obtain approved transfer method and reconcile all scheduled lessons before real use. No real data in unsigned staging.

Remaining: full dated enrolment/withdrawal history and changes preview per student, approved report/export format and provider configuration, daily reconciliation completeness and correction workflow (V4.2), live security/SSO/MFA and relief gaps (V4.0), protected multi-browser testing, recovery drill, ICT/privacy approval.
