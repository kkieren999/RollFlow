# V5.0 RC2.5 — Complete Administration Portal and System Management Experience

Cumulative from RC2.4 protected leadership branch commit 006313ab74a9305328ff93db068c8334f20a60a5. This is an unsigned synthetic staging candidate, not a production school deployment.

## Administrator experience

- Administration dashboard now links to a unified protected Administration Portal (/manage/system/) with directory and planning totals, pending import and verification review, operational entry points, role management and data reconciliation. The original directory and publication dashboard remains available.
- Account Review (/manage/system/accounts/) searches and filters account state, pending verification, administrator status, recorded grants and recorded timetable identity. Stable paginated results link to the original effective access and staff editing workflows. Recorded grants and verified ID flags are not assertions of current effective access.
- Audit & Activity (/manage/system/audit/) searches and pages separate security events and structured access changes, newest first, with links to structured history. No deletion, raw JSON dump, or export has been introduced.
- System Settings & Readiness (/manage/system/settings/) shows active publication, provenance warnings, operational source/roster status, date coverage, import counts, configuration links and all ten open release gates. It does not display secrets, claim backup verification, mutate deployment config or execute native system commands.
- Protected sidebar and dashboard links expose these pages to eligible system administrators only; the existing protected /manage/audit/ and /manage/settings/ entries redirect to the new pages. Existing permissions, data approval, attendance, publication restoration and workforce mutation checks remain authoritative. Leadership reports still require explicit grants. No schema changes.
