ADMINISTRATOR-ONLY · OFFLINE FILES

Bring OneSchool information into RollFlow

Choose the report you downloaded from OneSchool. RollFlow keeps the original files in a protected local archive so you can review them again. Nothing goes to GitHub or an external storage service.

1 · Student directory

SM110 — Dynamic Student List

Find: Look in OneSchool's reports for SM110 Dynamic Student List. Filter to the intended active enrolments and export as Excel.

Upload: one SM110_DynamicStudentList*.xlsx file.

RollFlow does: validate student IDs, year levels and roll classes; let you approve creating/updating the student directory.

Does not assign students to their subject classes.

2 · Staff teaching schedule

Whole-staff timetable

Find: The timetable export/report in OneSchool showing staff schedules, teaching periods, class codes and rooms.

Upload: a .pdf whole-staff timetable, or several PDF parts.

RollFlow does: preserve originals and report page/text checks for later parsing.

Teacher identity and class mapping require a verified PDF format before automatic allocation.

3 · Timetable line alignment

TTLineAlignmentExport

Find: OneSchool's timetable/line-alignment exports. Save every relevant file for the same reporting period.

Upload: multiple files at once using Ctrl or Shift. Accepts .csv, .xlsx and .pdf.

RollFlow does: checks each file, encrypts and groups all parts into one import batch for review.

No class allocation is applied until its actual field structure is verified.

4 · Student subject classes

ExportStudentClass

Find: Export Student Class in OneSchool's student/class reports. Save the original CSV.

Upload: one ExportStudentClass*.csv with EQID,Class_Name columns.

RollFlow does: match existing student EQIDs to known class codes, show unknown students/classes and let the administrator approve only valid links.

Import the SM110 student list and publish a timetable first. Teacher assignment remains separate and is never guessed.
